## Part I - Mitosis (diploid skin cell, 2n = 4)

### Parent cell setup
- Homologous pair 1: **A** (dad) and **a** (mom)
- Homologous pair 2: **B** (dad) and **b** (mom)
- DNA is replicated before mitosis, so each chromosome has two sister chromatids.

Legend for simple drawings:
- `X` shape = replicated chromosome (2 sister chromatids)
- `|` = single chromatid (after separation)
- `[SF]` = spindle fibers

### Prophase
```
   __________________________
  /                          \
 |   X(A)    X(a)   X(B) X(b) |
 |        (nuclear membrane   |
 |         breaking down)     |
  \__________________________/
```

### Metaphase (chromosomes line up single file at center)
```
   __________________________
  /                          \
 | [SF]--> X(A)              |
 | [SF]--> X(a)   |equator|  |
 | [SF]--> X(B)              |
 | [SF]--> X(b)              |
  \__________________________/
```

### Anaphase (sister chromatids separate)
```
   __________________________
  /                          \
 |  A|  a|   B|  b|   ->     |
 |     <-   |A  |a  |B  |b   |
 | (chromatids pulled apart) |
  \__________________________/
```

### Telophase + Cytokinesis
```
  _____________      _____________
 /             \    /             \
|   A  a  B  b  |  |   A  a  B  b  |
| (new nucleus) |  | (new nucleus) |
 \_____________/    \_____________/
```

### Daughter cells (final)
- **2 daughter cells**
- Each cell is **diploid (2n = 4)**
- Genetically **identical** to parent cell (barring mutation)

## Part II - Meiosis (diploid testis cell, 2n = 4)

Use same starting chromosomes: A, a, B, b.  
Show crossing over in Prophase I.

### Required structure labels (distributed across stages)
- homologous chromosomes
- sister chromatids
- genes
- spindle fibers
- centrosome
- centrioles
- nuclear membrane

### Prophase I
```
   ________________________________
  /                                \
 | Homologous pair 1: X(A) next to X(a) |
 | Homologous pair 2: X(B) next to X(b) |
 |  (synapsis/tetrads form)             |
 |  crossing over between non-sister    |
 |  chromatids occurs at chiasmata       |
 |  centrosomes + centrioles move poles  |
 |  nuclear membrane breaks down         |
  \____________________________________/
```

Crossing-over example (gene segment swap):
- Pair A/a after crossing over may include recombinant chromatids:
  - `A` and `a` (parental chromatids)
  - `A-a` and `a-A` (recombinant chromatids)

### Metaphase I
```
   __________________________
  /                          \
 | [SF]--> X(A)X(a)          |
 | [SF]--> X(B)X(b)  |equator|
 | (homologous pairs align)  |
  \__________________________/
```

### Anaphase I
```
   __________________________
  /                          \
 |  X(A)  X(B)   ->          |
 |          <-   X(a)  X(b)  |
 | (homologs separate;        |
 |  sister chromatids stay)   |
  \__________________________/
```

### Telophase I + Cytokinesis
```
  ________________      ________________
 /                \    /                \
|   X(A)   X(B)    |  |   X(a)   X(b)    |
|   (n = 2)        |  |   (n = 2)        |
 \________________/    \________________/
```

### Prophase II
```
  ________________      ________________
 /                \    /                \
| X(A)   X(B)      |  | X(a)   X(b)      |
| new spindles form|  | new spindles form|
 \________________/    \________________/
```

### Metaphase II
```
  ________________      ________________
 /                \    /                \
| [SF]--> X(A)     |  | [SF]--> X(a)     |
| [SF]--> X(B)     |  | [SF]--> X(b)     |
|      |equator|   |  |      |equator|   |
 \________________/    \________________/
```

### Anaphase II
```
  ________________      ________________
 /                \    /                \
| A|   B|   <- -> |  | a|   b|   <- -> |
| |A   |B         |  | |a   |b         |
| (sister chromatids separate in each cell) |
 \________________/    \________________/
```

### Telophase II + Cytokinesis (final daughter cells)
```
   _________   _________   _________   _________
  /         \ /         \ /         \ /         \
 |  A   B    | a   b    | A-a  B    | a-A  b    |
 | (n=2)     | (n=2)    | (n=2)     | (n=2)     |
  \_________/ \_________/ \_________/ \_________/
```

Note: Exact allele combinations vary due to crossing over and independent assortment; all final cells are haploid.

## Part III - Summary chart (Mitosis vs Meiosis)

| Cell Process Item | Mitosis | Meiosis |
|---|---|---|
| Creates | Somatic (body) cells | Gametes (sex cells: sperm/egg) |
| Definition | One division making two genetically identical diploid cells | Two divisions making four genetically different haploid cells |
| End Products | 2 daughter cells, 2n | 4 daughter cells, n |
| Steps | PMAT once (Prophase, Metaphase, Anaphase, Telophase) | PMAT I and PMAT II (two rounds) |
| Type of Reproduction | Asexual growth/repair | Sexual reproduction |
| Identical to parent cell? | Yes (usually) | No |
| When does cytokinesis occur? | Once, after Telophase | Twice: after Telophase I and Telophase II |
| How many times does parent cell divide? | 1 | 2 |
| Chromosome number at end | Maintained: diploid (2n), homologous pairs present | Halved: haploid (n), one chromosome from each homologous pair |
| Why is each important? | Growth, tissue repair, cell replacement | Genetic variation + correct chromosome number in offspring |

### Human chromosome numbers after each process
- **Mitosis (body cells):** 46 chromosomes after division in each daughter cell.
- **Meiosis (sex cells):** 23 chromosomes in each gamete.

## Part IV - Nondisjunction explanation

**Nondisjunction** is the failure of chromosomes to separate correctly:
- In **Meiosis I**, homologous chromosomes may fail to separate.
- In **Meiosis II** (or mitosis), sister chromatids may fail to separate.

This creates cells with abnormal chromosome numbers (**aneuploidy**), such as:
- **Down syndrome (Trisomy 21):** an extra chromosome 21 (47 total).
- **Turner syndrome (Monosomy X):** one missing sex chromosome in females (45, X).

### How abnormalities affect development
- **Down syndrome** may cause characteristic facial features, developmental delay/intellectual disability, hypotonia, and increased risk of heart/GI/thyroid disorders.
- **Turner syndrome** may cause short stature, ovarian insufficiency/infertility, delayed puberty, certain heart or kidney differences, and learning challenges (often visual-spatial or math-related), while intelligence is often in the typical range.

The specific effects vary by individual because gene dosage changes alter development in many tissues.
